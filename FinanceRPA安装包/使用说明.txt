FinanceRPA 加载宏安装说明
==========================

安装步骤
--------
1. 确认已安装 WPS 表格（2019 及以上版本）
2. 关闭所有 WPS 窗口
3. 双击 install.vbs
4. 点击 Yes 开始安装
5. 安装完成后打开 WPS 表格

验证安装
--------
1. 打开 WPS 表格
2. 查看功能区是否有「加载项」选项卡
3. 点击「加载项」应看到「FinanceRPA」工具组
4. 点击任意按钮测试功能

如果看不到按钮
--------------
1. 右键功能区 → 自定义功能区
2. 勾选「加载项」选项卡
3. 确定后重新打开 WPS

卸载方法
--------
1. 关闭 WPS
2. 删除启动文件夹中的 FinanceRPA.xlam
   （路径通常为：C:\Users\用户名\AppData\Roaming\Kingsoft\office6\startup\）
3. 重新打开 WPS，选项卡消失

功能列表
--------
1. 库存价值表清洗 — 数据清洗处理
2. 库龄表清洗 — 库龄数据清洗
3. 库龄期初变化分析 — 期初变化对比
4. 采购发票清洗 — 采购发票数据清洗
5. 固定资产隐藏列 — 隐藏指定列
6. 关于 — 版本信息

系统要求
--------
- WPS 表格 2019 及以上
- Windows 10/11
- 无需安装 Node.js 或其他依赖
